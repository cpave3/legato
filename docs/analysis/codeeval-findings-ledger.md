## G. Architecture intent (awaiting Cameron's decision; no code changes)

The 15 pre-existing rule violations, with what each import is used for at `471bfd24`:

| Importer | Engine package | What it uses | Kind |
|---|---|---|---|

| `internal/tui/app.go` | `ipc` | `ipc.Send`, `ipc.Message` | **behaviour** (sends to other processes) |
| `internal/tui/app.go`, `overlay/macro_picker.go` | `macros` | `Macro`; pure `AnyFavorite`, `SplitFavorites`, `AppliesTo*` | types + pure helpers |
| `internal/tui/app.go`, `board/*.go`, `overlay/workspace.go`, `plan/model.go`, `review/model.go` | `store` | `WorkspaceView`/`View*`, `PRMeta`, `TaskWorktree`, `PlanComment`, `ReviewHunkNote`, `ReviewStep` | types only |

| `config/config.go` | `macros` | `macros.Macro`, with its `UnmarshalYAML` and `Validate` | type with decoding |

The engine import that actually does something is TUI's use of `events.Bus` and `ipc.Send`. Every other import uses a value type, or a pure function of one.

Options for the intended rule:

1. **(Recommended)** TUI may import engine *value* types and pure helpers, not engine behaviour. Bus subscription and IPC sends move behind service interfaces. An architecture test with an allowlist of `(package, symbol)` pairs enforces the rule, so new behaviour imports fail. CLAUDE.md states it.
2. Strict: TUI imports no engine package. Service re-exports the types, through aliases or copies. That means churn in about 12 files, and the aliases add little.
3. Describe today's code as the rule. Not recommended: nothing would then stop TUI from importing behaviour.

For `config` → `engine/macros`:

- (a) Record a named exception: `config` may import the `macros` value package.
- (b) Move `Macro` into `config`, which owns configuration types. The server and TUI then read it from `config`. The engine package can't import `config`, so `engine/macros` would keep only what does not depend on it.
- (c) Make `macros` a leaf. It is not eligible today: it imports `yaml.v3`, and ADR 1 allows the standard library only.

C4 (`accountPathContains` ↔ `pathWithin`) waits on the same `config` decision.

New edges in the window: `cmd/legato` and `internal/service` → `claudeusage`/`codexusage`/`opencodeusage` (the allowed direction), and `internal/tui` → `config` (allowed: the TUI may read configuration). No new violations and no cycles.
