# Even Hub glasses app

`packages/even-hub/` is a proof of concept (LEG-163): an Even Realities G2 glasses app that shows the agents running now on two tabs (Active, needs-you first; Idle), opens an agent to show its recent conversation, and sends it a message the operator dictates. It is a TypeScript web app on the Even Hub SDK, and the first app in the `packages/` workspace. The user-facing page is [`site/src/content/docs/integrations/even-g2.md`](../../site/src/content/docs/integrations/even-g2.md); the package's README says how to run it.

## The `packages/` workspace

- One pnpm workspace rooted at `packages/` (`packages/pnpm-workspace.yaml`, `packages: ["*"]`), with one lockfile (`packages/pnpm-lock.yaml`). It is not at the repository root on purpose: pnpm finds the nearest `pnpm-workspace.yaml` above the current folder, so a root one would take over `pnpm install` in `web/`, `site/` and `browser-extension/`, installing at the root and ignoring their own lockfiles. Checked with pnpm 11.21. `desktop/` has its own `pnpm-workspace.yaml` (for `allowBuilds`), so it would be its own root either way.
- Shared by every package: `packages/eslint.config.js` (ESLint finds it from a package folder too; a package's `src/` gets browser globals, everything else Node's), `packages/tsconfig.base.json` (each package's `tsconfig.json` extends it), and `packages/package.json` (the lint dependencies; `pnpm run check` = lint, then each package's `typecheck` and `test`). `even-hub` type-checks `src/` with browser types only (`tsconfig.json`) and `dev/` and the Vite config with Node's (`tsconfig.node.json`), so Node in the app fails `typecheck`.
- Node 22.13 or later: pnpm 11 needs it (`engines` in each `package.json`).
- A package gives itself the scripts `typecheck` and `test`, and the `check` script runs them across the workspace.
- Wired in: `task packages:install` / `task packages:check`; CI job `packages` in `.github/workflows/ci.yml`; Cerberus checks `packages-lint`, `packages-typecheck`, `packages-test` through `.cerberus/run-packages-check.sh`; `.gitignore` entries for `node_modules`, `dist`, `.pack` and `.env.local` under `packages/`.
- A shell whose working directory is `packages/` or below makes Cerberus hooks look for `.cerberus/` there: run pnpm with `-C packages/...` from the repository root instead of `cd`. A stray `packages/.cerberus/` is litter (`.gitignore` already says so).

## The Even Hub platform, as the POC found it

From the docs at <https://hub.evenrealities.com/docs> and the npm packages, November 2026: SDK `@evenrealities/even_hub_sdk` 0.0.16, simulator `@evenrealities/evenhub-simulator` 0.9.5, packer `@evenrealities/evenhub-cli` 0.2.0, font metrics `@evenrealities/pretext` 0.1.4. None needs an Even account, except `evenhub login`/`create`/`upload`.

- **Where code runs.** In a WebView inside the Even Realities phone app (Chromium on Android, WKWebView on iOS). The glasses run no app code: the phone app sends them container layouts over Bluetooth and sends input back. `await waitForEvenAppBridge()` first; other calls before it silently do nothing.
- **Display.** 576×288 px, 4-bit greyscale shown as green, no fill. At most 4 image and 8 other containers on a page, exactly one with `isEventCapture: 1`. One firmware font, not monospaced, 27 px lines, no size or alignment. Text: 1000 characters on create or rebuild, 2000 on `textContainerUpgrade`; a captured container that overflows scrolls in firmware. List containers: 20 items of up to 64 characters, and no update in place. `textColor` 0–4 is per container.
- **Page calls.** `createStartUpPageContainer` once; `textContainerUpgrade` to change text without flicker; `rebuildPageContainer` for a new layout (flickers); `shutDownPageContainer(1)` from the root page (the system's exit dialog; review rejects a silent exit).
- **Input.** Up, down, click, double click, long press, contextual menu, from the temples or the R1 ring. The simulator reports a click on a captured text container as `{"sysEvent":{"eventSource":1}}` (no type: `CLICK_EVENT` is 0, which the SDK leaves out) and a double click as `sysEvent` type 3, not as `textEvent`s; scrolling comes as `textEvent` type 1 or 2. `startGlance` takes clicks and double clicks from either.
- **Network.** `fetch` and WebSockets from the WebView. A packed app may reach only the origins in `app.json`'s `network` whitelist (full origins, no wildcards), and normal CORS applies. Legato's CORS (`Access-Control-Allow-Origin: *`, `Authorization` allowed) passes. On Android the WebView may be suspended in the background, losing memory and open sockets.
- **Secrets.** The docs say never to put keys in an `.ehpk`: anyone can unpack one.
- **Simulator.** A Tauri window (WebKitGTK on Linux). `--automation-port N` serves `/api/ping`, `/api/screenshot/glasses` (RGBA PNG; lit is alpha > 0), `/api/screenshot/webview`, `/api/console` and `POST /api/input`. It does not draw the exit dialog: after `shutDownPageContainer(1)` the display goes blank and its log says `ShutDownPageContainer`. Under Legato's sandbox, the session's X display refuses it; `xvfb-run -a` works (`task even-hub:screenshots -- --headless`).

## How the app works

- `src/glance.ts`: `glance(agents, {tab, updatedAt, problem})` → the list page: `tab`, the tab labels (`Active N`, `Idle N`), `status` (a problem, or ""), `clock` and `items`. Running agents only (`status == "running"`). The active tab holds every agent not idle, ordered `waiting`, `error`, `working`, `background` (the TUI's sections and words, `internal/tui/agents/list.go`), each group oldest first, then the item `Idle agents (N) →` (`go: "idle"`); the idle tab holds the idle ones, then `← Active agents (N)`. An item that opens an agent has `open: <task_id>`. Items are cut by `fitItem` to the list's width (`pxTruncate`'s measure) and to 63 UTF-8 bytes, with `…`; more than 20 end in `+N more`.
- `src/layout.ts`: one spacing scale for every page (8 px margin, 4 px gap and padding, 1 px borders), the header row, the frame under it and the hint line at the foot, and `center` (leading spaces; the firmware only aligns left). A box is `boxHeight(padding, border)` tall: a 27 px line inside its padding and border, else the simulator (and likely the firmware) gives it a scrollbar.
- `src/agent.ts`: an agent's pages share a header: `badge` (its state, `● needs you`, in a bordered box, bright) and `title` (task and title, dim). `agentPage(agent, read)` → `{badge, title, items, hint}`: the feed, a list of one-line entries (`● Asks: …` for the open permission or question, then the entries newest first: `You: …`, `Agent: …` for what it said, `Legato <kind>: …` or `Agent <id>: …` for a tagged user turn read as `web/src/lib/legatoMessage.ts` reads it, a tool call as `<mark> <tool>: <what>` with `▶` running, `▲` failed, `·` done and an MCP tool by the part after its last `__`), each cut by `fitItem` and each keeping the entry in full as `detail`; at most 20. `entryPage(agent, item)` shows one entry's `detail` in the frame (within 2000 characters). `dictationPage(agent, step)` draws the steps of a message with the step in the badge (`● Listening`, `Message`, `Sending`, `Sent`, `▲ Not sent`, `▲ Problem`). Every page's `hint` is centred: `Tap: expand · Hold: dictate · Double tap: back` on the feed. A problem from sending keeps the text, and a tap sends it again.
- `src/legato.ts`: the four calls. `fetchAgents`; `fetchConversation` (409 → "runs in a terminal", 404 → "no longer running"); `transcribe` (`POST /api/voice/transcribe` `{transcription_only: true, pcm: <base64>}`: never `false`, which would have Legato type the text into the agent's pane itself; 404 → "Transcription is off", a 200 with `error`, empty text → "Heard nothing."); `sendMessage` (`POST /api/agents/{task}/chimera/send` `{content}`, which reaches only an agent with a native endpoint and never starts one; 409 busy, 503 no native endpoint, 403 the dev server's "sending is off"). `POST /api/tasks/{id}/agent` was not used for sending because it starts an agent when none runs. `chimera/send` does not queue: the web UI sends over `/ws` (`agent_message` with `queue: busy`, to `AgentService.QueueMessage`), so a message to a working agent waits there, while the glasses get 409 and keep the text to send again. An HTTP route to `QueueMessage` would let the glasses queue too (see Ideas). Any other failed answer is Legato's `{"error"}` when it gave one; the dev server's 502 is "Can't reach Legato". Every call gives up after `CALL_TIMEOUT_MS` (10 s; transcription `TRANSCRIBE_TIMEOUT_MS`, 30 s): "Legato took too long to answer". The dictated text is the operator's own words, so it carries no `[legato …]` tag (see [Development notes](dev-notes.md)).
- `src/app.ts`: `startGlance(bridge, legato)` (a `LegatoClient` of the four calls). Every change of state runs through one promise queue (reads, presses, the recording clock), so nothing races; sound (`audioEvent.audioPcm`) is kept outside it as it arrives. A press is judged against what the glasses showed when it came (`seen()`: the view, the dictation step, the list's items), not when its turn comes: a tap made while "Transcribing…" showed is dropped, so it cannot send the transcript that replaced it, and a list press is matched by the item's name among the items then shown (by index only when the SDK gives no name). The next poll is set in a `finally`, so a failed call to the glasses or to Legato does not stop polling. `draw` redraws a page (`createStartUpPageContainer` once, then `rebuildPageContainer`; a `false` from it is an error and the page stays undrawn, so the next refresh draws it again) only when its layout key changes: the list's key is the tab and items, a feed's its task and items (a list cannot change in place, so a new entry redraws it and the highlight goes back to the top), a text page's its task. Otherwise only text that changed goes out with `textContainerUpgrade`. A page is drawn with text over 1000 characters left empty, then updated (the limits differ). Presses come from `listEvent`, `textEvent` or `sysEvent` (`press`); a list press is matched to an item by `currentSelectItemName`, then `currentSelectItemIndex`. Pages: the list page (tabs, problem, clock, a framed list), an agent's feed (badge, title, framed list `feed`, hint) and its text page (the same with a framed text `body`, for an entry or a message; switching between them updates in place). Hold to talk: `LONG_PRESS_EVENT` on a feed, an entry or a problem starts recording, and `LONG_PRESS_RELEASE_EVENT` stops it (a release is not judged against what was shown: the hold ahead of it in the queue started the recording); a tap stops it too, should a release not come. A tap on a feed line opens it (by name, as with the list); double tap goes back one step. Dictation: `audioControl(true, AudioInputSource.Glasses)` (`false` from it → "The microphone didn't start."), a one-second clock, a stop at 60 s, `audioControl(false)` on stop, cancel and backgrounding.
- `src/settings.ts`: Legato's address and token on the phone, in the bridge's `getLocalStorage`/`setLocalStorage` (`legato.url`, `legato.token`). `saveSource` refuses an address that is not HTTPS (plain `http://` only to loopback) and keeps a saved token only for the same origin. With no address saved, the app calls the build's `VITE_LEGATO_URL` (set by `scripts/pack.mjs` to the packed origin) or `/legato` on the page's own server.
- `dev/legato-dev.ts`: the Vite dev server's `/legato` path, answering only the four calls (by method and path, a task ID being one segment; anything else `404`). Fixtures: `fixtures/agents.json` (or `LEGATO_FIXTURE`), `fixtures/conversation.json` as any agent's, a set transcript, and a send that is only logged. With `LEGATO_URL` and `LEGATO_TOKEN`: passes them on with the token, and refuses a send (`403`) unless `LEGATO_ALLOW_SEND=1`. A POST's body is rebuilt from the one field the call needs (`{transcription_only: true, pcm}`, `{content}`), never passed on as sent: Go's `encoding/json` matches keys without regard to case and keeps the last, so a body with a second `TRANSCRIPTION_ONLY: false` would otherwise turn transcription-only off and have Legato type into a pane. `crossSiteRefusal` refuses a POST that is not `application/json` (a page on another site could send plain text without a preflight) and a request with `Sec-Fetch-Site: cross-site`. A body over 8 MB is answered 413. The dev server checks no caller: anyone who reaches it (with `--host 0.0.0.0`, the network) reads every agent's conversation, and with `LEGATO_ALLOW_SEND=1` can message them. `LEGATO_*` are read with `loadEnv(mode, root, "LEGATO_")` in `vite.config.ts` and never reach the bundle (only `VITE_*` would). Node trusts Legato's generated certificate only with `NODE_EXTRA_CA_CERTS` (the CA is `<data_dir>/certs/ca.pem`, or `GET /api/ca-cert`).
- `scripts/pack.mjs`: `vite build` with `VITE_LEGATO_URL` the packed origin (never the token), then `evenhub pack` with a copy of `app.json` whose network whitelist is `LEGATO_URL`'s origin (`.pack/app.json`) and `--sdk-ver` of the installed SDK. Output `dist/legato.ehpk`. `app.json` asks for `network` and `g2-microphone`.

## Verified

- Unit tests at the seams: `glance`, `agentPage`/`dictationPage`, the four calls (fake `fetch`), `startGlance` (a fake bridge that keeps what each page shows, fake timers; including presses that arrive while a call is under way), `answerLegato`/`devSettings`/`crossSiteRefusal`, `saveSource`.
- The screenshots in `packages/even-hub/docs/screenshots/` come from `task even-hub:screenshots -- --headless`; the site's `site/src/assets/even-g2-*.png` are `agents.png` and `agent.png` laid on black (regenerate them when those change) (the glasses' RGBA framebuffer is transparent where nothing is lit).
- In simulator 0.9.5 under Xvfb on the fixtures: both tabs, opening an agent, and a dictated message from listening to "Sent" (`task even-hub:screenshots -- --headless`). Under Legato's sandbox there is no sound server: the default input fails (`snd_pcm_open … Host is down`, and the app says "The microphone didn't start."), so the headless run records silence from `--aid alsa:null`.
- Against a scratch Legato under `env -i` with TLS: the list (right token `[]`, wrong token `401` passed on, no CA `502`); a conversation (`404` "running agent not found"); a transcription (`404` "voice not enabled"); a send refused by the dev server (`403`), and with `LEGATO_ALLOW_SEND=1` passed on to Legato (`503` "no chimera endpoint"). No send has reached a live agent: that needs a running agent in a scratch Legato, so a task.
- Against the operator's own Legato, on request, read-only, the token given to the dev server alone through `legato credential exec`, and sends refused by the dev server: 17 running agents (2 working, 1 background, 14 idle) on the two tabs; conversations of native agents. One agent's conversation was still loading after 2 seconds.
- Not on hardware: neither sideloading nor a packed build has run on real glasses, and dictation has not heard real speech.

## Ideas for later

- An HTTP route to `AgentService.QueueMessage` (as `/ws`'s `agent_message` with `queue: busy`), so a message dictated to a working agent waits for it instead of being refused.
- A token scoped to what the glasses do (read agents and conversations, transcribe, send), instead of the whole web token kept on the phone.
- Run dictation end to end against a scratch Legato with `voice.whisper_url` set and a native agent running, and on real glasses (the audio format is assumed to be the 16 kHz mono s16le the simulator documents).
- Answer what an agent asks from its page: its permission's allow and deny, a question's options, through the contextual menu (up to 10 items).
- Use `internal/engine/endofturn` (or Legato's voice session, `/api/reeve/voice/session`) to stop recording when the operator stops speaking, instead of a second tap.
- Keep the list's highlight on the same agent across a redraw: the SDK has no call to set it, so the app would have to redraw less, or keep its own cursor in a text container.
- Show the title alone for ad-hoc agents, whose task IDs (`ixkm5deo`) say nothing.
- Hold `/ws` while in front and read on `agents_changed`, with polling as the fallback (the token would have to go in `/ws`'s query string).
- Notify on a change to `waiting`: the SDK has no notification call. The app would have to be in front, or Legato's ntfy notifications would have to reach the phone.
